# Kometa: Gravity Flight

Бесплатная аркада для iPhone одним пальцем. Держи, и планета притянет комету; отпусти, и комета полетит прямо.

- Сайт и поддержка: https://maryrussova26.github.io/kometa-game/
- Играть в браузере: https://maryrussova26.github.io/kometa-game/play.html
- Политика конфиденциальности: https://maryrussova26.github.io/kometa-game/privacy.html
